# Sandrik - Crypto Research Workspace

## MCP Servers

### Dune Analytics (configured at user scope)
The **Dune MCP server** is available for blockchain and crypto research. Use it to:
- Query on-chain data (Ethereum, Solana, Base, Arbitrum, etc.)
- Analyze DeFi protocols, DEX volumes, TVL, token flows
- Track wallet activity and whale movements
- Monitor protocol metrics and smart contract interactions
- Run and create Dune SQL queries for custom analysis

When the user asks about on-chain data, crypto analytics, blockchain metrics, or DeFi research, use the Dune MCP tools to fetch real data rather than relying on stale knowledge.
